A Duolingo style language learning app built with Next.js, TypeScript and Postgres. It includes authentication, Stripe payments, an admin panel, and a lesson flow with keyboard shortcuts (keys 1 to 4 select an answer) and audio feedback. Deployed on Vercel.

Live demo: https://duolingo-clone-next-14.vercel.app
https://duolingo-clone-next-14.vercel.app/
